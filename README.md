# 📊 Agregador de Informações para Imposto de Renda – Excel

Este repositório contém uma ferramenta desenvolvida em Microsoft Excel para auxiliar na organização de dados essenciais para a declaração de Imposto de Renda.  
O objetivo é centralizar informações pessoais, informes bancários e registros de rendimentos em um único arquivo, com navegação intuitiva e validações que tornam o preenchimento mais simples e seguro.

---

## 📁 Estrutura do Repositório

```
README.md        → documentação do projeto  
organizador.IR.xlsx   → arquivo Excel com as três tabelas e botões de navegação  
```

---

## 🧩 Objetivo do Projeto

Criar um **agregador de dados no Excel** que permita ao usuário:

- Registrar informações pessoais do titular  
- Organizar informes bancários e dados financeiros  
- Registrar entradas de renda por categoria  
- Navegar entre abas por meio de botões interativos  
- Utilizar validações automáticas para evitar erros de preenchimento  

A proposta é oferecer uma solução prática, amigável e funcional para uso anual na preparação da declaração.

---

## 🗂️ Estrutura da Planilha

A ferramenta é composta por **três abas principais**, todas conectadas por botões de navegação.

---

### 1. **Aba “Titular”**

Área destinada ao preenchimento dos dados pessoais:

- Nome completo  
- Documentos (CPF, RG, etc.)  
- Endereço  
- Informações de contato  
- Outros dados relevantes  

**Recursos incluídos:**

- Campos organizados e validados  
- Botão para navegar para as demais abas  

---

### 2. **Aba “Informes”**

Espaço para registrar informações bancárias e documentos relacionados:

- Banco  
- Tipo de conta  
- Valor em conta ou saldo informado  
- Referência ao arquivo PDF do informe de rendimentos  

**Recursos incluídos:**

- Estrutura padronizada para facilitar conferência  
- Campo para registrar o local do PDF  
- Botão de navegação  

---

### 3. **Aba “Notas”**

Tabela destinada ao registro das entradas de renda ao longo do ano.

Campos disponíveis:

- Data do recebimento  
- Categoria (CNPJ, Freelance, Holerite)  
- Valor recebido    

**Recursos incluídos:**

- Validação de dados para categorias  
- Tabela formatada para facilitar filtros e organização  
- Botões para navegar entre abas  

---

## 🧭 Navegação

A planilha utiliza **botões interativos** que permitem alternar entre as abas com apenas um clique, tornando o uso mais fluido e intuitivo.

---

## 🛠️ Recursos Utilizados

- Microsoft Excel  
- Validação de dados  
- Formatação de tabelas  
- Hiperlinks internos  
- Botões de navegação  
- Organização visual e lógica  

---

## 🚀 Como Utilizar

1. Baixe o arquivo `organizador_IR.xlsx` deste repositório  
2. Abra no Excel (versão desktop recomendada)  
3. Preencha as informações nas abas conforme necessário  
4. Utilize os botões para navegar entre as seções  
5. Atualize os dados ao longo do ano para manter tudo organizado
